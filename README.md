# Data Analysis 学习项目集合

本项目是 [roadmap.sh](https://roadmap.sh/) 数据分析学习路径中多个实战项目的集合，涵盖了数据清洗、探索性数据分析（EDA）、数据可视化、网页爬虫和 SQL 数据库查询等核心数据分析技能。

## 项目列表

| 序号 | 项目 | 说明 | 核心技能 |
|------|------|------|----------|
| 1 | [清理 Netflix 数据集](清理%20Netflix%20数据集/) | Netflix 影视数据集的缺失值处理、类型拆分与标准化 | pandas 数据清洗 |
| 2 | [泰坦尼克号幸存者预测](泰坦尼克号幸存者预测/) | 从性别、年龄、舱位等维度分析影响幸存率的关键因素 | EDA、matplotlib、seaborn |
| 3 | [药品销售数据分析](药品销售数据分析/) | 药品每日销售趋势分析、品种销量对比与季节性观察 | pandas 聚合、matplotlib 折线图 |
| 4 | [Python 职位列表抓取器](Python%20职位列表抓取器/) | 从网页抓取招聘信息并导出为 CSV | requests、BeautifulSoup |
| 5 | [使用 SQLite 和 Python 进行查询](使用%20Sqllite%20和%20Python%20进行查询/) | 通过 SQL 查询 Chinook 数据库并进行可视化分析 | sqlite3、SQL、pandas |

## 技能覆盖

- **Python 3.x** — 所有项目的基础编程语言
- **pandas** — 数据读取、清洗、分组聚合与统计分析
- **matplotlib / seaborn** — 柱状图、折线图、热力图等数据可视化
- **requests / BeautifulSoup** — 网页数据抓取与 HTML 解析
- **sqlite3 / SQL** — 关系型数据库查询与多表关联分析
- **Jupyter Notebook** — 交互式数据探索与分析

## 使用方法

1. 克隆本仓库：
   ```bash
   git clone <repo-url>
   cd "Data Analysis Study Project Collection"
   ```

2. 安装依赖：
   ```bash
   pip install pandas matplotlib seaborn requests beautifulsoup4 jupyter
   ```

3. 进入各子项目目录，打开对应的 `.ipynb` 文件或运行 `.py` 脚本即可查看分析过程和结果。
