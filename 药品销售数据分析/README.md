# 药品销售数据分析 — 销售趋势与品种对比

这是一个基于 Python 的药品每日销售数据分析项目。它使用 `pandas` 进行数据加载、清洗与聚合统计，通过 `matplotlib` 绘制月度销量趋势图，从总销售量、月度 Top3、日均销售量等维度对比不同药品的销售表现。

## 项目目标
- 练习使用 `pandas` 加载 CSV 数据并进行日期列的类型转换（`to_datetime`）。
- 掌握使用布尔掩码按年月筛选数据，结合 `loc` 提取子集进行分析。
- 学习使用 `sum`、`mean`、`sort_values`、`idxmax` 等聚合与排序方法进行统计。
- 练习使用 `groupby` 按月份分组汇总，计算各月总销量。
- 练习使用 `matplotlib` 绘制折线图，包括填充区域、网格线等美化元素。
- 通过分析结果回答业务问题：哪些药品销量最高？销量是否存在季节性趋势？

## 功能特性
- 自动读取药品每日销售数据（`salesdaily.csv`），将 `datum` 列转为 `datetime` 格式。
- 自动提取药品列（去掉日期及 Year/Month/Hour/Weekday Name 四列辅助列），便于批量聚合。
- **分析 1：总销售量排名** — 计算样本期内各药品总销售量，降序排列并输出最高品种。
- **分析 2：指定月份销量 Top3** — 按年月筛选数据，输出该月销量前 3 的药品；同时输出指定年份的全年销量冠军。
- **分析 3：日均销售量** — 计算各药品的日均销量，找出日均表现最好的品种。
- **分析 4：月度销量趋势图** — 对 R03 药品按月汇总销量，绘制折线图观察季节性波动。
- 折线图配置中文字体、网格线、半透明填充区域，支持中文标题与轴标签。

## 技术栈
- **Python 3.x**
- **pandas**: 数据读取、日期处理、分组聚合与统计分析。
- **matplotlib**: 绘制月度销量折线图。

## 数据集说明
本项目使用药品销售数据集（`archive/salesdaily.csv`），记录了 2014 年至 2019 年期间 8 种药品的每日销售数量，包含以下字段：

| 列名 | 说明 |
|------|------|
| datum | 日期（YYYY-MM-DD） |
| M01AB | 药品 M01AB 的当日销售量 |
| M01AE | 药品 M01AE 的当日销售量 |
| N02BA | 药品 N02BA 的当日销售量 |
| N02BE | 药品 N02BE 的当日销售量 |
| N05B | 药品 N05B 的当日销售量 |
| N05C | 药品 N05C 的当日销售量 |
| R03 | 药品 R03 的当日销售量 |
| R06 | 药品 R06 的当日销售量 |
| Year | 年份（辅助列） |
| Month | 月份（辅助列，1-12） |
| Hour | 小时（辅助列） |
| Weekday Name | 星期名称（辅助列） |

## 关键发现
- **销量冠军**：N02BE 以 63005.40 units 的总销量遥遥领先，日均销售 29.92 units，是第二名 N05B（18645.74 units）的 3 倍以上。
- **月度稳定性**：在 2015年1月、2016年7月、2017年9月三个不同时间段中，N02BE 均稳居月销量第 1，表现非常稳定。
- **品种分层明显**：N02BE 和 N05B 属于第一梯队（年销量过万），R03、M01AB 属于第二梯队（年销量 6000-12000），N05C 销量最低（1249.96 units）。
- **季节性趋势**：R03 药品的月度销量折线图可直观反映其季节性波动规律，便于后续库存和供货决策。
