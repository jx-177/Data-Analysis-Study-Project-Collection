# 泰坦尼克号幸存者预测 — 数据探索与可视化分析

这是一个基于 Python 的 Titanic 数据集探索性数据分析（EDA）项目。它使用 `pandas` 进行数据清洗与统计分析，通过 `matplotlib` 和 `seaborn` 将分析结果可视化，从性别、年龄、舱位等级等维度探究影响乘客幸存率的关键因素。

## 项目目标
- 练习使用 `pandas` 加载 CSV 数据并进行初步的数据探索（形状、类型、缺失值）。
- 学习数据清洗的基本方法：缺失值识别、缺失率计算及填充策略（中位数、常量填充）。
- 掌握使用 `groupby` 进行分组聚合，计算不同维度下的生存率。
- 学习特征工程基础：将连续型变量（年龄）离散化为分类变量（年龄段）。
- 练习使用 `matplotlib` 和 `seaborn` 绘制柱状图、热力图等可视化图表。
- 通过分析结果回答业务问题：哪些因素对乘客幸存率影响最大？

## 功能特性
- 自动读取 Titanic 训练数据集（`train.csv`），展示列名与数据结构。
- 输出数据统计描述（`describe`、`info`）及缺失值分布。
- 对缺失值进行针对性处理：
  - **Cabin（客舱号）**：缺失率 77%，填充为 `"Unknown"`。
  - **Age（年龄）**：缺失率 20%，使用中位数填充。
  - **Embarked（登船港口）**：缺失 2 个值，填充为 `"Unknown"`。
- 创建年龄分组特征 `AgeGroup`（儿童/青少年/青年/中年/老年）。
- **分析 1：性别与生存率** — 按 `Sex` 分组计算平均生存率，绘制柱状图。
- **分析 2：年龄与生存率** — 按 `AgeGroup` 分组计算平均生存率，绘制柱状图。
- **分析 3：舱位等级与生存率** — 按 `Pclass` 分组计算平均生存率，绘制柱状图。
- **分析 4：特征相关性热力图** — 选取数值型列计算相关系数矩阵，通过热力图直观展示各特征之间的线性关系。
- 每个分析结果都配有柱状图可视化，图表支持中文标题与标签。
- 结果直接展示在 Jupyter Notebook 中，无需额外导出。

## 技术栈
- **Python 3.x**
- **pandas**: 数据读取、清洗、分组聚合与统计分析。
- **matplotlib**: 绘制柱状图等统计图表。
- **seaborn**: 绘制相关系数热力图。

## 数据集说明
本项目使用 Kaggle Titanic 竞赛数据集（`titanic/train.csv`），记录了 891 名泰坦尼克号乘客的个人信息及是否幸存，包含以下字段：

| 列名 | 说明 |
|------|------|
| PassengerId | 乘客 ID |
| Survived | 是否幸存（0 = 遇难，1 = 幸存） |
| Pclass | 舱位等级（1 = 一等舱，2 = 二等舱，3 = 三等舱） |
| Name | 乘客姓名 |
| Sex | 性别（male = 男性，female = 女性） |
| Age | 年龄 |
| SibSp | 同行的兄弟姐妹 / 配偶数量 |
| Parch | 同行的父母 / 子女数量 |
| Ticket | 船票编号 |
| Fare | 票价 |
| Cabin | 客舱号 |
| Embarked | 登船港口（C = Cherbourg，Q = Queenstown，S = Southampton） |

## 关键发现
- **性别**：女性生存率（74.2%）远高于男性（18.9%），女性在事故中优先获救。
- **年龄**：儿童（0-12 岁）生存率最高（57.4%），符合"妇女儿童优先"的救援原则。
- **舱位等级**：一等舱生存率（63.0%）远高于三等舱（24.2%），反映出社会阶层对生存机会的显著影响。
- **相关性**：`Pclass` 与 `Survived` 呈负相关（-0.34），舱位等级越低幸存率越低；`Fare` 与 `Survived` 呈正相关（0.26），票价越高幸存率越高。
